# 스트로마톨라이트 형성 시뮬레이터

고등학교 통합과학 수업용 학습 웹앱입니다. 스트로마톨라이트의 **얇은 층 하나가 만들어지는 과정**을 표면 확대 화면에서 단계별로 관찰하고, 조건을 하나씩 바꾸어 기준 조건과 비교하도록 설계했습니다.

## 구성

- **탭 1 · 층이 만들어지는 과정** — 기본 조건에서 ① 미생물 매트 → ② 퇴적물 도착 → ③ 포획과 결합 → ④ 새 표면 형성 → ⑤ 광물 침전 → ⑥ 한 층 완성 을 학생이 직접 단계를 넘기며 관찰합니다. 각 단계는 애니메이션이 끝나면 자동으로 넘어가지 않고 정지합니다. 마지막 단계 뒤 "오랜 시간 반복해 보기"로 전체 단면이 층층이 성장하는 모습을 봅니다.
- **탭 2 · 조건에 따라 달라지는 모습** — 퇴적물 공급량 또는 물의 흐름 중 **한 가지 변인**만 바꾸어, 기준 조건과 두 화면을 동시에 재생하며 비교합니다. 결과는 점수가 아니라 관찰 가능한 항목(붙잡힌/쓸려간 퇴적물, 새 표면 형성, 층의 모습)으로 정리됩니다.

## 사용 방법

`index.html` 파일 하나만 브라우저(크롬 권장)에서 열면 바로 실행됩니다. 설치·빌드가 필요 없고, 인터넷은 글꼴 표시에만 사용됩니다. 키보드 ←/→(단계 이동), 스페이스(일시정지)를 지원합니다.

## 교사 수정 지점 (`index.html` 안)

- `STEPS` — 단계 이름·설명 문장·"왜 그럴까?" 해설·재생 시간
- `buildScene()` — 확대 관찰 장면의 입자 수, 미생물·점액질·결정 배치
- `MACRO_REPS`, `buildMacro()` — 반복 장면의 층 수와 층 모양
- `OBS`, `SUPPLY`, `FLOWP` — 탭 2 조건별 수치와 관찰 결과 문구
- `<style>` 상단 `:root` — 색상 테마
