# 스트로마톨라이트 형성 시뮬레이터

고등학교 통합과학 수업용 학습 웹앱입니다. 스트로마톨라이트의 **얇은 층 하나가 만들어지는 과정**을 표면 확대 화면에서 단계별로 관찰하고, 조건을 하나씩 바꾸어 기준 조건과 비교하도록 설계했습니다.

## 구성

- **탭 1 · 층이 만들어지는 과정** — 확대 관찰 화면에서 구슬형 세포가 이어진 남세균 필라멘트, 점액질(EPS) 젤과 실, 명암이 있는 퇴적물 입자가 상호작용하는 모습을 단계별로 관찰합니다. ④ 새 표면 형성 단계에서는 학생이 직접 **햇빛 비추기** 버튼을 눌러, 빛이 비칠 때 일부 남세균이 공극을 따라 이동·성장해 새 매트를 만드는 과정을 확인합니다(햇빛을 꺼도 이미 만들어진 매트와 점액질은 유지). ⑥에서 카메라가 천천히 축소되고, "오랜 시간 반복해 보기"에서 자연스러운 층상 돔으로 이어집니다.
- **탭 2 · 조건에 따라 달라지는 모습** — 한 가지 변인(퇴적물 공급량/물의 흐름)만 바꾸어 같은 난수 시드·같은 입자 스케줄로 두 화면을 동시 재생합니다. 결과 카드는 고정 문구가 아니라 **실제 시뮬레이션 집계값**(공급/포획/유실 입자 수, 새 매트 형성 비율, 층 두께·불규칙성)에서 생성되며, 기준 대비 화살표와 미니 막대로 표시됩니다.

## 사용 방법

`index.html` 파일 하나만 브라우저(크롬 권장)에서 열면 바로 실행됩니다. 설치·빌드가 필요 없고, 인터넷은 글꼴 표시에만 사용됩니다. 키보드 ←/→(단계 이동), 스페이스(일시정지)를 지원합니다.

## 교사 수정 지점 (`index.html` 안)

- `STEPS` — 단계 이름·설명 문장·"왜 그럴까?" 해설·재생 시간
- `buildScene()` — 확대 관찰 장면의 입자 수·크기, 미생물·점액질·결정 배치
- `MACRO_REPS`, `buildMacro()` — 반복 장면의 층 수와 층 모양
- `SUPPLY_N`, `FLOWP`, `startGrow()` — 탭 2 조건별 수치와 매몰 판정 기준
- `PAL`(스크립트), `:root`(스타일) — 색상 팔레트
