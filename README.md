# 스트로마톨라이트 형성 시뮬레이터

고등학교 통합과학 수업용 조작형 학습 웹앱입니다. 학생이 햇빛·퇴적물 공급·물의 흐름·탄산칼슘 침전 조건을 직접 조절하고 사이클을 반복하면서, 스트로마톨라이트의 층상 구조가 **"미생물층이 퇴적물 위로 다시 성장하는 반복"** 으로 만들어진다는 원리를 체험하며 이해하도록 설계했습니다.

## 사용 방법

- `index.html` 파일 하나만 있으면 됩니다. 브라우저(크롬 권장)에서 파일을 열면 바로 실행됩니다. 설치·빌드·인터넷 연결이 필요 없습니다(글꼴만 온라인일 때 더 예쁘게 보입니다).
- 왼쪽에서 조건을 고르고 **한 사이클 진행** 또는 **5회 자동 진행**을 누르세요.
- 한 사이클은 ① 퇴적물 공급 → ② 점액질 부착 → ③ 위로 다시 성장 → ④ 광물 침전 순서로 애니메이션됩니다.
- 오른쪽 패널에서 이번 사이클의 결과 해설과, 시추 코어처럼 읽는 층 기록을 볼 수 있습니다.
- 하단의 탐구 질문과 관찰 기록 칸은 수업 활동지로 활용할 수 있습니다. 관찰 기록은 해당 컴퓨터의 브라우저에 자동 저장됩니다.

## 교사 수정 지점

`index.html` 안에서 다음 부분을 찾아 값만 바꾸면 됩니다.

- `<script>` 상단의 `OPT` — 각 조건 선택지가 성장·퇴적·침전에 미치는 배율
- `BASE` — 층 한 겹의 기본 두께
- `computeCycle()` 안의 점수 계산과 피드백 문장 — 판정 기준과 해설 문구
- `<style>` 상단의 `:root` CSS 변수 — 색상 테마
