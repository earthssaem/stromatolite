# 스트로마톨라이트는 어떻게 만들어질까?

고등학생이 "남세균의 활동으로 퇴적물이 붙잡히고, 그 위에서 남세균이 다시 성장하는 과정이 반복되면서 스트로마톨라이트의 층상 구조가 형성된다"는 핵심을 직관적으로 이해하도록 만든 학습 웹앱입니다. 세부 용어와 수치보다 "왜 여러 층이 생기는가?"에 집중합니다.

## 구성

- **교사 시연 · 한 층이 만들어지는 과정** — 해저 표면을 가까이서 보는 확대 화면에서 4단계를 차례로 봅니다.
  1. 남세균이 매트를 형성한다
  2. 남세균이 점액질을 분비한다
  3. 퇴적물이 쌓인다 (물의 흐름을 따라 옆에서 들어와 일부만 점액질에 붙잡힘)
  4. 남세균이 다시 성장한다 (일부 가닥이 퇴적물 위로 이동하고 새 표면을 따라 매트가 형성됨)
  - 각 단계는 2~3초 동안 천천히 재생되며 자동으로 다음 단계로 넘어가지 않습니다. 이전 / 다음 단계 / 처음으로 버튼으로 이동합니다.
- **학생 체험 · 과정을 반복해 층 쌓기** — 남세균 매트가 있는 상태에서 세 과정(점액질 분비, 퇴적물 쌓임, 남세균 성장) 중 다음에 일어날 과정을 직접 고릅니다.
  - 순서와 다른 선택은 실패가 아니라 관찰 결과로 보여 줍니다. (점액질 없이 퇴적물 → 대부분 쓸려 감, 퇴적물 없이 성장 → 현재 표면에서만 성장)
  - 한 층이 완성되면 경계를 잠시 강조하고 `다음 층 쌓기`로 다음 주기를 시작합니다. 층 수에 제한이 없으며, 층이 많아지면 화면의 세로 비율이 자연스럽게 축소됩니다.
  - 층이 2개 이상이면 `층의 단면 보기`로 전체 구조의 경계를 확대해 볼 수 있고, 닫으면 이어서 층을 쌓을 수 있습니다.

## 사용 방법

`index.html` 파일 하나만 브라우저(크롬 권장)에서 열면 바로 실행됩니다. 설치·빌드가 필요 없고, 인터넷은 글꼴(Pretendard) 표시에만 사용됩니다. 데스크톱과 모바일에서 모두 동작하며 버튼은 키보드로도 조작할 수 있습니다.

## 교사 수정 지점 (`index.html` 안)

- `STEPS` — 교사 시연 단계의 제목·설명
- `LAYER_T`, `MAT_T`, `EPS_T` — 층·매트·점액질 막의 두께(화면 비율)
- `FULL` — 매트를 이루는 남세균 가닥 수
- `baseProfile()`, `layerProfile()` — 바닥과 각 층의 굴곡 모양
- `:root`(스타일) — 색상 팔레트
