# 스트로마톨라이트의 층은 어떻게 만들어질까?

고등학교 통합과학 수업용 학습 웹앱입니다. 학생이 "미생물 매트가 퇴적물을 붙잡고, 새로운 표면 매트가 형성되는 과정이 반복되면서 층이 만들어진다"는 핵심 원리를 직접 체험하며 이해하도록 설계했습니다.

## 구성

- **탭 1 · 한 겹이 만들어지는 과정** — 미생물 매트 표면을 확대한 화면에서 6단계(① 표면의 미생물 매트 → ② 퇴적물 유입과 침강 → ③ 퇴적물 포획과 결합 → ④ 새 표면의 미생물 매트 형성 → ⑤ 층의 안정화와 광물 침전 → ⑥ 얇은 한 층이 남음)를 관찰합니다.
  - ②는 자동 재생으로 물에 실려 온 입자들이 흘러 들어와 일부가 가라앉습니다.
  - ④는 자동 재생되며, 완료 후 화면 중앙 경계선을 드래그해 **형성 전·후를 비교**할 수 있습니다.
  - ⑥의 "이 과정이 반복되면?" 버튼으로 탭 2로 이어집니다.
- **탭 2 · 반복되어 스트로마톨라이트가 되기까지** — 탭 1의 얇은 한 층에서 시작해, ① 같은 드래그로 형성 주기를 직접 2회 반복해 층을 쌓고, ② "오랜 시간의 반복 보기"로 카메라가 축소되며 돔형 단면까지 성장하는 타임랩스를 본 뒤, ③ **확대경을 드래그**해 완성된 단면 내부의 층 구조(살아 있는 표면 매트, 묻힌 이전 매트, 퇴적물, 층 경계, 탄산염 결정)를 관찰합니다. 퀴즈·점수·조건 비교는 없습니다.

## 사용 방법

`index.html` 파일 하나만 브라우저(크롬 권장)에서 열면 바로 실행됩니다. 설치·빌드가 필요 없고, 인터넷은 글꼴 표시에만 사용됩니다. 마우스·터치 드래그, 키보드 ←/→(단계 이동)·스페이스(일시정지)를 지원합니다.

## 교사 수정 지점 (`index.html` 안)

- `STEPS` — 탭 1 단계 이름·설명·"왜 그럴까?" 해설·재생 시간
- `buildScene()` — 확대 관찰 장면의 입자·미생물·점액질·결정 배치
- `T2`, `t2Plan()`, `AUTO_S` — 탭 2 층 쌓기 주기의 두께·입자·자동 재생 시간
- `MACRO_REPS`, `buildMacro()` — 돔 단면의 층 수와 층 모양
- `PAL`(스크립트), `:root`(스타일) — 색상 팔레트
